# 测量学基础：信度、ICC 与误差

## 1. 真分数模型

经典测量理论（CTT）把观测分拆成：

```
X = T + E
```

- `X` 观测分（本例是 LLM 给出的档位分）
- `T` 真分数（该回答"应有"的分数——由评分标准定义，不可直接观测）
- `E` 随机误差（同一回答重复评分间的波动）

信度（reliability）定义为真分数方差占比：

```
ρ = σ²(T) / σ²(X) = σ²(T) / (σ²(T) + σ²(E))
```

ρ ∈ [0,1]，越大表示观测分越能代表真分数。**这就是"稳定性"的严格定义**。

## 2. ICC 的三种形式与选型

ICC（Intraclass Correlation Coefficient）是 ρ 的估计量，形式取决于设计：

| 形式 | 适用设计 | 本例是否适用 |
| :--- | :--- | :--- |
| ICC(1,1) | 每个被试由**不同**评分者评，评分者随机 | ✗ |
| ICC(2,1) | 每个被试由**同一批**评分者评，推断到评分者总体 | **✓ 用这个** |
| ICC(3,1) | 同上，但评分者固定（不推断总体） | 可选，作为上界参考 |

本例中"评分者"就是"同一温度下的多次重复"，每份回答都被同一批重复评过，
且我们想推断到"该温度下的评分行为总体"，所以用 **ICC(2,1)**。

### 双向随机效应（two-way random effects）的方差分解

把每份回答 i 在重复 j 下的得分 `x_ij` 分解：

```
x_ij = μ + r_i + c_j + e_ij
```

- `μ` 总均值
- `r_i ~ N(0, σ²_r)` 回答的随机效应（**这就是真分数方差**）
- `c_j ~ N(0, σ²_c)` 重复次的随机效应（顺序效应，理想为 0）
- `e_ij ~ N(0, σ²_e)` 残差

则：

```
ICC(2,1) = σ²_r / (σ²_r + σ²_c + σ²_e)
```

注意分母包含 `σ²_c`——**绝对一致性（absolute agreement）**：
我们要求重复之间给出"同一个分数"，而不是"排序一致"。

## 3. SEM 与 MDC

**SEM（Standard Error of Measurement）** —— 单次评分的典型误差：

```
SEM = SD_observed × √(1 − ICC)
```

**MDC（Minimal Detectable Change）** —— 两次评分之差中，多大的差异才算真实变化：

```
MDC95 = 1.96 × √2 × SEM
```

实用意义：若某学员的两次测评总分差小于 MDC95，**不能判定他进步了**，
那只是评分误差。报告里给出 MDC95 能让分数解释有据可依。

## 4. 泛化理论（G-theory）：多面设计

CTT 只分"真分数 + 误差"，G-theory 进一步拆解误差来源：

```
σ²(X) = σ²(p)     被试（对象）
      + σ²(t)     温度（固定面，但在 G 研究里可当随机面看）
      + σ²(i)     重复次
      + σ²(pt)    被试 × 温度
      + σ²(pi)    被试 × 重复
      + σ²(ti)    温度 × 重复
      + σ²(pti)   三方交互 + 残差
```

**关键读数**：

- `σ²(p)` 大 → 有真差异，量表有区分能力（好）
- `σ²(t)` 大 → 温度造成系统偏移（坏，说明配置影响分数绝对值）
- `σ²(pt)` 大 → 温度对不同回答影响不同（坏，说明没有全局最优温度）
- `σ²(i)` 与 `σ²(pti)` → 纯随机误差（越小越好）

**G 系数**（类似 ICC）：

```
Eρ² = σ²(p) / [σ²(p) + σ²(i)/n_i]
```

其中 `n_i` 是重复次数。用它可以直接回答"要重复几次"：

```
n_i = σ²(i) × Eρ²_target / [σ²(p) × (1 − Eρ²_target)]
```

**D 研究（decision study）**：给定目标 G 系数（如 0.90），反解所需重复次数。
这是"重试几次才够"的理论答案。

## 5. 排序稳定性

除分数绝对一致，还要看**相对名次**是否稳定（公平性的排序面）：

- **Kendall's W**（协调系数）：多组评分的名次一致性，0 无一致、1 完全一致
- **Spearman ρ**：重复之间的名次相关
- **Top-k 稳定性**：重复评分中，前 k 名成员的集合重合度

名次比分数对尺度不敏感，是"排序公平性"的直接证据。

## 6. 样本量与精度

估计 ICC 的置信区间宽度主要取决于**对象数**（回答数）、次要取决于重复数：

- 对象数 ≥ 30 才能把 ICC 的 95% CI 压到 ±0.15 以内
- 重复数从 2 增到 5 收益明显，5 → 10 收益递减

因此设计上优先保证对象数（本例 330 个问答对，充足），重复数取 5 左右即可。
