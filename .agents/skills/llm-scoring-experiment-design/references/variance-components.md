# 方差分量估计与混合效应模型

本文件给出把嵌套设计**正确**分析成方差分量的具体做法。

## 1. 为什么不能用普通 ANOVA / 简单均值

嵌套设计里，同一受访者的多条回答共享个人风格，不是独立样本。
若按"330 个独立回答"分析：

- 误差自由度被高估 → p 值过小 → **假阳性**
- 组间差的置信区间过窄 → 误判"显著"

正确做法二选一：

- **方案 A（推荐）**：混合效应模型，显式声明随机效应
- **方案 B（保守）**：先把同一受访者的多个回答聚合成一个值，
  再在**受访者层级**做检验（n=30，自由度真实）

报告里必须写明用了哪个方案。若两者结论冲突，以 A 为准并解释差异。

## 2. 线性混合模型（LMM）建模

对"分数 ~ 温度"的关系，在嵌套结构下建模：

```python
# 伪代码：statsmodels / lme4 / pymer4 均可
score ~ temperature * tier            # 固定效应：温度、水平组、交互
random = ~ 1 | person                 # 受访者随机截距（吸收个人风格）
random = ~ 1 | person:slot            # 回答嵌套于受访者（吸收题目难度差异）
```

- `temperature * tier` 的交互项：**检验"温度对不同水平的人影响是否不同"**
  → 这是公平性的核心检验（好温度应对所有人同等稳定）
- 随机截距 `1|person` 对应 `σ²(p)`；`1|person:slot` 对应回答层差异
- 残差方差即 `σ²(ε)`

**估计方法**：REML（限制最大似然），小样本下方差分量估计更少偏差。

## 3. 直接算方差分量（G-theory 的 ANOVA 法）

若要手算，用三向交叉/嵌套的均方反解。对"回答 × 温度 × 重复"设计：

```
MS_person     ← 受访者间
MS_slot(person) ← 回答（嵌套于受访者）
MS_temp       ← 温度
MS_slot×temp  ← 回答 × 温度
MS_resid      ← 残差（回答 × 温度 × 重复 的组内）
```

简化近似（忽略部分高阶交互）：

```
σ²(回答)      ≈ [MS_slot(person) − MS_resid] / (n_temp × n_rep)
σ²(回答×温度) ≈ [MS_slot×temp − MS_resid] / n_rep
σ²(残差)      ≈ MS_resid
```

**负估计**（方差为负）在样本小时会出现，按 0 处理并在报告里说明。

## 4. Bootstrap 置信区间（尊重嵌套）

报告所有关键统计量的 CI 时，**按受访者整块重采样**（cluster bootstrap）：

```python
for b in range(2000):
    persons_b = resample(persons, replace=True)        # 重采样人，不是行
    rows_b = concat(rows of each sampled person)       # 连带其所有回答
    stat_b = compute_statistic(rows_b)
CI = percentile(stat_b, [2.5, 97.5])
```

为什么要按人重采样：同一个人内部的回答相关性高，按行重采样会
**低估方差、得到过窄的 CI**（与 §1 同一个错误）。

## 5. 多重比较校正

扫描 10 个温度，就有 C(10,2)=45 个两两比较。控制错误发现率：

```python
from statsmodels.stats.multitest import multipletests
rejected, p_adj, _, _ = multipletests(p_values, alpha=0.05, method="fdr_bh")
```

报告时同时给原始 p 与校正后 p；若结论依赖校正前后的差异，说明结论不稳健。

## 6. 最小可检测变化（MDC）

"温度 0.2 和 0.3 的差异不显著" —— 这句话只有在给出检测能力时才有意义：

```
MDC95 = 1.96 × √2 × SEM
```

若两个温度的均值差 < MDC95，正确的表述是
"**在当前样本量下无法区分**"，而不是"两者相同"。

## 7. 收敛与诊断

LMM 要检查：

- 残差 QQ 图与残差-拟合图（正态性、同方差）
- 随机效应是否必要（似然比检验：去掉 `1|person` 是否显著变差）
- 奇异拟合（singular fit）→ 随机效应结构过复杂，逐步简化

评定量表常不满足正态假设，此时用**有序 logistic 混合模型**更合适
（分数是 0/0.25/0.5/0.75/1 五档，本质是序数）。
若两种模型结论一致，报告主用 LMM 并注明序数模型的稳健性检验结果。
