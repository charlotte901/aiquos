# LLM 评分实验设计

用测量学（psychometrics）与实验设计（DOE）的标准，设计"AI 打分器"的评估实验。
核心立场：**打分器是一件测量仪器**，评估它就要量化仪器误差，而不是看几次输出像不像。

## 一、先把"稳定性"和"公平性"定义成可测量量

含糊的目标（"更稳一点""更公平"）无法设计实验，必须先操作化。

### 稳定性 = 信度（reliability）

同一份回答被反复评分，分数应一致。三个层次，由弱到强：

| 指标 | 定义 | 用途 |
| :--- | :--- | :--- |
| 一致率 agreement | 重复评分中完全相同的比例 | 直观，但对粗粒度量表会虚高 |
| 组内标准差 within-item SD | 同一回答多次评分的 SD | 描述误差幅度，单位是"分" |
| **ICC 组内相关系数** | 真分数方差 / 总方差 | **主指标**。跨回答、跨量表可比 |
| SEM 测量标准误 | SD × √(1−ICC) | 单次评分的误差有多大，可直接算 CI |

**ICC 选型**：每个回答被同样这批评分条件重复测 → 用 ICC(2,1)（two-way random, single measure, absolute agreement）。要在报告里写明用哪个 ICC 形式，这是审稿人必查项。

### 公平性 = 效度 + 无关变量不敏感（validity & invariance）

公平不是"分数一样"，而是**分数只随该随的变量变**：

1. **区分度（discrimination）**：真实水平不同的人，分数要拉开。
   组间差 Δ = mean(高) − mean(低)；标准化后类似 Cohen's d。
2. **校准（calibration）**：评分均值应贴近设计意图的档位，不该系统性偏高/偏低。
3. **无关特征不变性（invariance）**：改变与质量无关的表面特征，
   分数不该变。**这是最容易被忽略、也最能暴露问题的一项**，用扰动实验测（见 §4）。
4. **排序稳定（rank stability）**：重复评分后，受访者的相对名次是否稳定。
   用 Kendall's W 或 Spearman ρ 衡量。

> 只测稳定性会选出"全给同一个分"的退化配置（方差为 0，最"稳定"）。
> 只测区分度会选出"随机给分"的配置（碰巧拉开差距）。
> **两者必须同时报告，并给出联合判据。**

## 二、实验结构：这是嵌套设计，不是简单重复

评分实验天然带**三层嵌套 + 一层交叉**：

```
水平组 (低/中/高)
  └─ 受访者 (嵌套于组)
       └─ 回答 (嵌套于受访者，如同一个人的多个话题/轮次)
            × 温度 (交叉 —— 每个回答都在所有温度下被评)
            × 重复 (嵌套于 回答×温度)
```

**为什么必须显式建模嵌套**：同一位受访者的多条回答不独立（有个人风格），
把它们当独立样本会**低估标准误、虚报显著性**。分析时用混合效应模型或
泛化理论（G-theory）分解方差分量，至少也要在聚合层级上取平均后再比较。

**方差分量分解（G-theory）** 能直接回答"误差主要来自哪"：

```
σ²(回答)        ← 真实差异（越大越好，这是信号）
σ²(温度)        ← 温度造成的系统偏移（不该存在）
σ²(重复|回答×温度) ← 纯随机误差（越小越好）
σ²(回答×温度)   ← 温度与个体的交互（不该存在：好配置对所有回答都稳）
```

判据：σ²(重复) 和 σ²(回答×温度) 都要小，σ²(温度) 接近 0。

## 三、自变量与搜索策略：先粗扫，再梯度细化

**不要一上来就高密度扫描**——成本高且容易在噪声里过拟合。三阶段：

1. **粗扫（coarse）**：8–10 个等距点覆盖全量程，看曲线的形状
   （单调？有平台？还是无规律）。这一步的结论是"最优区间大概在哪"。
2. **梯度细化（refine）**：在粗扫最优点的 ±1 个步长内，用 1/4 步长加密。
   若曲线有平台，取平台中点（对参数漂移更鲁棒）；若单峰，取峰顶。
3. **确认（confirm）**：在最终推荐值上，用**独立的大样本**重测并给出置信区间。
   这一步是防"选择偏差"（在噪声上挑出的最优点会向乐观偏），必须做。

**必设对照组**：把"当前线上配置"作为基线一起测，否则报告无法回答"改了有没有用"。

## 四、公平性专项：扰动实验（perturbation / invariance test）

这是本类实验最有价值也最容易省略的部分。做法：

围绕同一批回答，构造**仅表面特征不同**的配对（matched pairs）：

| 扰动维度 | 构造方式 | 期望 |
| :--- | :--- | :--- |
| 长度 | 原回答 + 无关铺陈（不增加要素） | 分数不变（反作弊条款明写"字数不换分"） |
| 措辞 | 同内容换口语/书面语气 | 分数不变 |
| 术语密度 | 塞入术语但不给做法 | 分数**不该上升**（应命中反作弊规则） |
| 顺序 | 打乱句子次序但信息等价 | 分数不变 |

**统计量**：配对差值的均值（系统偏差）+ 配对 t 检验或 Wilcoxon。
再算**温度对这些差值的调节效应**——这正是"公平性随温度如何变化"的答案。

## 五、统计推断的纪律

- **多重比较**：温度点数 ≥ 5 时必然要做校正。用 Benjamini–Hochberg FDR 控制，
  报告校正前后两套 p 值。
- **效应量优先于 p 值**：报告 ICC、Cohen's d、Δ 的**置信区间**（Bootstrap，
  按受访者整块重采样以尊重嵌套结构）。样本量小的时候 p 值没有话语权。
- **功效分析**：若结论是"没差异"，必须给出"能检测到的最小效应"，
  否则无法区分"真没差异"和"样本不够"。用 MDC（最小可检测变化）表达：
  `MDC95 = 1.96 × √2 × SEM`。
- **不要用均值代替分布**：评定量表常出现天花板/地板效应，报告分布与
  中位数，均值仅作辅助。

## 六、报告必须包含的要素

一份能经得起方法学检查的报告，至少给全这些：

1. **测量模型**：稳定性与公平性各自的定义、选用的指标及理由
2. **数据来源**：样本如何构造、是否含人为标注、有无泄漏（打分数据不得含水平线索）
3. **实验矩阵**：自变量水平、重复次数、总调用量与成本
4. **主结果**：温度 vs 各指标的曲线，带误差带（不是光秃秃折线）
5. **方差分解**：误差来源占比，说明为什么选该温度
6. **公平性结果**：扰动实验的系统偏差与显著性
7. **推荐值与置信区间**，以及**对当前线上配置的改进量**
8. **局限**：样本代表性、模型版本绑定、结论能否外推
9. **可复现**：脚本路径、随机种子、原始结果文件

## 七、常见陷阱（踩过就别再踩）

| 陷阱 | 后果 | 规避 |
| :--- | :--- | :--- |
| 把嵌套数据当独立样本 | 显著性虚高 | 混合模型 / 聚合到受访者层级 |
| 用"输出逐字相同"当温度生效判据 | 误判（批处理+浮点非结合必然有差异） | 看分布级指标（熵、选择占比） |
| 只报最优温度不报区间 | 无法判断稳健性 | 报平台区间与确认实验 |
| 在噪声峰值上取最优点 | 过拟合，换批数据就失效 | 三阶段搜索 + 确认实验 |
| 忽略 API 侧参数被静默忽略 | 扫了个寂寞 | **先验证参数有效**（见 §8） |
| 打分数据里带水平标签 | 模型可从字段名反推 | 输入只保留回答文本 |

## 八、开测前必做：验证自变量真的有效

**在扫描之前**，先用小样本确认该参数确实影响输出。判据不能是"逐字相同"，
而要看分布级证据：

```text
1. 越界值是否被拒绝？          → 证明参数被服务端接收
2. 极低 vs 极高设置下，输出的选择分布熵是否变化？
   → 熵应随设置单调变化，否则参数对该模型无效
3. 是否存在"某个模式忽略采样参数"的情况？
   → 查官方文档；推理模型常在 thinking 模式忽略 temperature
```

任何一项不通过，先解决通道问题再谈扫描——否则整套实验的自变量是空的。
