# PDF / Word 题目导入

入口：管理端 → 题库管理 → 导入 PDF / Word。

支持 PDF、DOC、DOCX，单次 10 MB 以内。阿里云文档智能解析文字后，由现有模型整理为选择题、判断题。其他题型不自动转换。单次最多 100 题，超过 10000 字需拆分文档。

解析结果只进入预览；核对并编辑题干、选项、答案、解析、难度、类别及能力维度后，点击确认导入。缺失答案不自动补造，需人工补齐；可移除不适合导入的题目。确认后沿用题库发布流程，生成新版本。

服务端 `.env.local` 配置 ALIYUN_ACCESS_KEY_ID、ALIYUN_ACCESS_KEY_SECRET 和已有的 DEEPSEEK_API_KEY。开通文档智能服务，并为专用 RAM 用户授权 AliyunDocmindFullAccess。不要把密钥放入前端或 Git。

采用阿里云官方 @alicloud/docmind-api20220711 SDK，SubmitDocParserJobAdvance 上传、QueryDocParserStatus 查询、GetDocParserResult 读取解析结果。任务按账号隔离，30 分钟失效；服务重启后需重新上传。部署端需要支持 Node.js SDK 及安装项目 dependencies。

真实 Word 样例已用于联调；样例只生成预览，不发布到正式题库。服务端使用官方公共端点 docmind-api.aliyuncs.com。

导入确认时仅向当前最新题库追加新题，其他教师期间发布的修改会保留；与当前库或本次文档重复的题目会跳过。解析可取消，最长等待五分钟；同一任务的并发轮询共用一次题目整理结果。

`npm run build` 的 server 目录包含 package.json 和锁文件。将该目录单独部署到 Node.js 时，需先在该目录执行 `npm ci --omit=dev` 安装运行依赖，再接入服务入口。云服务接口形状参考[阿里云官方文档](https://help.aliyun.com/zh/document-mind/developer-reference/document-parsing-large-model-version)。
