## 审核发现与修复

- dev JSON 中间件构造 URL 时丢失 query，正确班级口令也会查询 404。透传 search，并在实际 HTTP 和浏览器中回归搜索及重新加入。
- 新教师尚无班级时原检查会放过跨班下发。存在受管班级时一律按所有权过滤学员、作业和下发范围，并增加越权测试。
- 种子/核验脚本使用的 findAccountByLogin 未导出。增加使用同一账号规范化逻辑的查询接口。
- Sites 产物漏 worker/http.js、storage.js、comprehensive-score.js 等运行依赖。补齐清单并实测打包模块启动及初始化。
- PR 的备份存储与主干原子存储重复。统一实现，损坏时读取有效备份；两份均损坏则停止写入，避免清空账号。
- 首次生产存储接线存在并发请求抢跑风险。共享初始化 Promise，配置 AIQUOS_DATA_DIR 时自动导入初始班级，实际 4 个并发登录均成功。
- 核验脚本硬编码 9/10 月，进入 11 月后错误失败。改为根据记录日期切换月份。
- 报告撰写 payload 中 null 维度不再被 Number(null) 转成零分。
